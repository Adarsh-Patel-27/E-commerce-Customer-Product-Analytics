# E-commerce Customer & Product Analytics

An end-to-end data analytics project analyzing customer behavior, purchasing patterns, product performance, and customer retention using the Olist Brazilian E-commerce dataset.

## 📌 Project Overview

This project explores real-world e-commerce data to understand:

- Customer purchasing behavior
- One-time vs. repeat customers
- High-value customer segments
- Product and category performance
- Revenue and order trends
- Customer retention and cohort behavior
- Customer experience through delivery time and review scores

The analysis combines **Google Sheets for initial data exploration** with **Python for data cleaning, analysis, segmentation, and visualization**.

---

## 🎯 Objectives

The main objectives of this project are:

1. Clean and prepare raw e-commerce data for analysis.
2. Analyze revenue and order trends over time.
3. Understand customer purchasing behavior.
4. Segment customers using RFM analysis.
5. Identify high-performing product categories.
6. Analyze customer retention using cohort analysis.
7. Examine the relationship between delivery time and customer reviews.
8. Generate actionable business insights from the data.

---

## 📊 Dataset

The project uses the **Olist Brazilian E-commerce Dataset**, a publicly available dataset containing approximately 100,000 e-commerce orders.

The dataset includes information about:

- Customers
- Orders
- Order items
- Payments
- Products
- Sellers
- Reviews
- Product categories
- Customer locations

### Main datasets used

| Dataset | Description |
|---|---|
| Customers | Customer identifiers and location |
| Orders | Order status and timestamps |
| Order Items | Products, prices, freight and sellers |
| Products | Product information and categories |
| Reviews | Customer review scores |
| Payments | Payment information |
| Sellers | Seller information |
| Category Translation | Product category translations |
